# 备份与恢复

配置备份适合搬迁看板设置。数据库备份用于恢复完整站点数据，例如历史快照和加密凭据。

## 导出与导入共享配置

在「数据管理」点击「导出配置」。文件包含已保存的共享设置、访问规则、来源地址及已上传背景。采集历史、登录凭据与来源密钥需要另行备份。导出的 JSON 含站点地址和权限信息，请妥善保管。

通过「数据导入」选择 JSON，检查预览后点击「导入到草稿」，再点击「保存配置」。目标发生变化的来源需先重测并按需重新填写凭据。备份未包含的现有来源会停用并保留。导入会替换现有草稿，保存前可放弃修改。

「恢复全局默认设置」会把站点、模块、日程、链接等恢复为默认值，并按确认提示处理来源与旧权限设置。数据和加密凭据保留，确认后立即保存并生效。

## D1

升级前在 D1 控制台查看可用的 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/) 时间点或保留导出。恢复之前先确认目标数据库和时间点，暂停会写入的服务。恢复数据库也需要原版本的解密密钥。

## SQLite

```sh
pnpm db:backup:node /var/backups/nozoki/manual.sqlite
```

目标文件必须尚不存在。命令使用 SQLite 在线备份并执行 `quick_check`。运行中的数据库使用在线备份命令，单独复制主数据库文件可能漏掉 WAL 中的写入。

恢复时停止网页服务与采集，把完整备份复制到新的数据路径，检查运行账号权限，并更新 `NOZOKI_SQLITE_PATH`。验证看板、登录和来源凭据后再恢复采集。
