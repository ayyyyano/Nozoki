# 备份与恢复

配置备份适合搬迁看板设置。数据库备份用于恢复完整站点数据，例如历史快照和加密凭据。

## 导出与导入共享配置

在「数据管理」点击「导出配置」。文件包含已保存的共享设置、访问规则、来源地址及已上传背景。登录凭据与来源密钥需要另行备份。导出的 JSON 含站点地址和权限信息，请妥善保管。

### 采集历史归档

导出时可选中「包含采集历史」，将余额观测、每日用量和 Codex 日用量的聚合数据写入备份。历史仅用于归档与离线查阅，无法导入任何部署；需要长期保留时建议定期导出。

### 跨部署迁移凭据

导出时可选中「包含凭据」，将来源凭据和 CLIProxyAPI 身份密钥写入备份；默认不包含。文件包含明文机密，请安全传输和保存，并在导入完成后删除。新部署须先配置自己的凭据加密密钥及所需 Secret，导入后凭据会使用新部署的密钥加密。来源访问批准随导入验证同步恢复；验证未通过的来源保留连接配置但不迁移凭据。此备份不含管理员登录凭据。

导入预览中选择「验证并继续」，需要测试的来源会依次验证。验证通过的凭据与访问批准在保存配置后一并生效；未通过的来源保留连接配置，但不迁移凭据，预览会显示原因。核对结果后选择「导入到草稿」并保存。

若目标已有 CLIProxyAPI 身份密钥，或来源标识发生变化，系统会拒绝覆盖身份密钥，以保护现有账户权限映射。

通过「数据导入」选择 JSON，检查预览后点击「导入到草稿」，再点击「保存配置」。目标发生变化的来源需先重测并按需重新填写凭据。备份未包含的现有来源会停用并保留。导入会替换现有草稿，保存前可放弃修改。

「恢复全局默认设置」会把站点、模块、日程、链接等恢复为默认值，并清除全部来源凭据与采集历史（余额观测、每日用量、Codex 日用量、采集记录与快照，对话框会列出待删行数）。删除不可恢复，需要保留时先导出「包含采集历史」的备份。腾讯默认行情恢复启用，采集调度与登录状态保留。输入确认文字后立即保存并生效。

## D1

升级前在 D1 控制台查看可用的 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/) 时间点或保留导出。恢复之前先确认目标数据库和时间点，暂停会写入的服务。恢复数据库也需要原版本的解密密钥。

## SQLite

```sh
pnpm db:backup:node /var/backups/nozoki/manual.sqlite
```

目标文件必须尚不存在。命令使用 SQLite 在线备份并执行 `quick_check`。运行中的数据库使用在线备份命令，单独复制主数据库文件可能漏掉 WAL 中的写入。

恢复时停止网页服务与采集，把完整备份复制到新的数据路径，检查运行账号权限，并更新 `NOZOKI_SQLITE_PATH`。验证看板、登录和来源凭据后再恢复采集。
