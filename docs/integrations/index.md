# 接入数据源

1. 登录后台，打开「来源接入 → 添加来源」，选择来源类型。
2. 填写实例的公网 HTTPS 服务根地址和提供方要求的凭据。DeepSeek、Tailscale 等固定地址来源使用预设。
3. 点击「测试并批准」。成功后添加来源，并点击「保存配置」。连接验证通过后，批准随全局配置提交。
4. 在「主页模块」启用对应模块，等待采集后查看首页详情。

每种类型可新建一个实例，历史实例会保留。来源类型和协议在创建后固定。站点最多保存十个来源。监控模块可同时使用两个提供方，行情模块优先匹配已启用的腾讯来源。

## 编辑、验证或删除

保存之前可编辑现有实例、更新凭据或撤销访问批准。修改地址、认证或连接参数后重新测试。测试凭证有效十分钟，并绑定会话、配置版本和当前来源目标。验证结果记录上次成功时间，正式快照由采集写入。

凭据栏的圆点是占位提示。点击「编辑」输入新值，清除凭据或删除来源也在保存后生效。受保护的数据历史可能阻止删除，此时可停用来源。遇到限流、协议不匹配或验证过期时，调整配置并按提示重试。
