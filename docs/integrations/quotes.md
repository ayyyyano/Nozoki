# 行情

新数据库预置腾讯行情，默认标的是 QQQM 和 VOO。打开「主页模块 → 自选行情 → 首页展示」添加或编辑标的，填写市场、代码、名称和刷新间隔，保存后检查采集结果。

| 来源       | 适用范围与配置                                                                                                              |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| 腾讯行情   | 使用 `tencent-us-v1`，支持美股。默认映射 QQQM 到 `QQQM.OQ`、VOO 到 `VOO.AM`。其他标的填已核实的完整代码，如 `AAPL.OQ`。     |
| Yahoo 行情 | 使用 `yahoo-chart-v8`，支持美股、沪深与港股的已登记市场代码。腾讯未配置或停用时自动选择 Yahoo。腾讯临时失败时保留当前来源。 |

## 理解报价和走势

涨跌按昨收计算。腾讯历史走势使用近五个交易日的前复权收盘价，快照会区分上游报价时间和采集时间。首页展示价格和走势，详情包含可取得的昨收、振幅和成交量。过期判断会参考美股纽约时间 16:00、A 股上海时间 15:00 的常规工作日收盘时刻，跳过周末。节假日与临时休市未纳入这项判断。
