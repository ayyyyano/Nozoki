# DeepSeek

在 [DeepSeek 平台](https://platform.deepseek.com/api_keys)创建 API Key。在「来源接入」添加 DeepSeek，填写密钥并测试，保存后启用同名模块。实例地址由官方预设提供。

卡片展示近七日剩余余额。今日柱随最新观测更新，历史柱取站点时区当天最后一次成功观测。缺少采集的日期为空。日终前会安排采集，服务中断时只能保留当天已有的结果。

在「主页模块」将 DeepSeek 设为「管理员」后，访客会看到固定模糊占位。该占位由服务端生成，不包含真实金额或走势。需要公开金额时检查模块权限及已保存的访客限制。见[访客权限](/guide/privacy.md)。
