# Sleepy

连接支持 Sleepy v5 的实例，通过公网 HTTPS 提供 `/api/meta` 和 `/api/status/query`。在「来源接入」选择 Sleepy，填写服务根地址，例如 `https://sleepy.example.com/`。测试并保存后启用「设备」。

各客户端上报的字段可能不同。设备卡片展示可取得的状态文字、前台应用和可识别的电量。无有效电量时使用中性圆环。状态更新时间代表最后一次状态变动，不能用于判断设备心跳或充电是否正常。

在「主页模块 → 设备」选择首页设备、设置别名和图标。启用「访客隐藏设备应用与状态」后，首页及详情都会过滤对应字段。客户端突然停止上报时，可在 Nozoki 详情和 Sleepy 实例内对比更新时间。
