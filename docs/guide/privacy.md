# 访客权限

在「主页模块」打开模块编辑对话框。公开模块向访客提供允许展示的字段。管理员模块通常可选「隐藏」或「登录提示」。DeepSeek 设为管理员时，访客看到固定模糊占位，真实余额只在管理员会话下按权限提供。

## 按模块设置

- **设备**可向访客隐藏应用与状态文字。
- **Tailscale**可分别设置节点名称和 IP 的公开、遮蔽或隐藏方式。
- **Codex**可单独设置 5 小时额度、周额度及对应重置进度的访客可见性。遮蔽状态使用固定占位。
- **常用链接**支持逐条设置权限。服务状态等模块也会应用已保存的访问限制。

首页与详情使用同一套服务端权限。已有高级字段限制随配置保留，并继续约束访客数据。保存后，用新的隐私窗口检查首页和详情。
