# 看板模块

| 模块      | 首页内容                     | 数据来源                 |
| --------- | ---------------------------- | ------------------------ |
| DeepSeek  | 近七日剩余余额               | DeepSeek                 |
| 设备      | 设备状态、可选电量           | Sleepy                   |
| Tailscale | 节点连接状态、可选地址       | Tailscale                |
| Codex     | 两个可选的额度或重置进度圆环 | CLIProxyAPI              |
| 在干嘛    | 当前日程、倒计时和进度       | 后台日程                 |
| 自选行情  | 价格、日涨跌及走势           | 腾讯行情或 Yahoo         |
| 常用链接  | 最多四项快捷链接             | 后台链接                 |
| 服务状态  | 最近的监控状态与延迟         | UptimeFlare、Uptime Kuma |

## 选择首页内容

打开「主页模块」，点击相应模块进入编辑对话框。可修改模块标题、启用状态和可见性。模块顺序由站点自动安排。设备、Tailscale 节点、监控和常用链接可在各自模块里调整条目顺序。设备首页最多四项，Tailscale 和服务状态各最多八项。

有更多内容时，卡片标题旁会显示详情按钮。更新、观测时间和过期信息可在详情中查看。采集失败时会保留上一次有效快照，时间和状态以模块详情为准。

设备、Tailscale 和服务状态卡片的标题栏另有刷新按钮，位于详情按钮左侧。点击它会**立即为该卡片关联的数据源执行一次全新采集**，不必等待下一次定时采集；采集完成后看板会自动更新。采集仍复用站点原有的请求额度与防重复机制，因此每次点击最多启动一轮采集，正在采集时不会重复启动。

为避免频繁点击给数据源和服务器带来压力，同一张卡片在 15 秒内只响应一次刷新，短时间内重复点击会被忽略。无论采集成功还是失败，页面底部都会弹出提示说明结果。

## 日程和快捷链接

在「在干嘛」中选用基础作息或自定义周计划。基础模式可配置活动时段、午休、休息日和特殊日期。自定义周计划支持每日安排、模板和日期例外。设置 IANA 时区后，可在「实际效果预览」检查某个日期的结果。

在「自选行情」和「常用链接」的「首页展示」中使用列表和编辑对话框。点击「应用」将条目加入草稿，再点击「保存配置」提交。链接允许分别设置为公开或管理员可见。
