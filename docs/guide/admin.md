# 管理后台

点击首页账号图标登录，也可直接访问 `/login`。后台位于 `/admin`。

| 导航     | 操作                                 |
| -------- | ------------------------------------ |
| 站点外观 | 站点名称、配色、背景和卡片效果       |
| 主页模块 | 启停模块、编辑首页内容与访客权限     |
| 来源接入 | 连接地址、凭据、刷新间隔和验证       |
| 数据管理 | 导出配置、导入配置和恢复全局默认设置 |

## 编辑与保存

点击列表行打开编辑对话框。关闭对话框后，已经应用到全局草稿的修改仍会保留。对话框内的「保存配置」与后台顶栏提交同一份草稿。要撤销整份草稿，从管理菜单选择「放弃修改」。

另一个窗口先保存时，后台会提示版本冲突。先核对已保存版本，再合并需要保留的改动。切换来源地址或更新凭据后，应在保存前重新测试。

## 验证记录

「测试并批准」检查当前连接及协议。验证通过后，访问批准随配置保存。来源列表中的上次成功验证时间可以在刷新后查看。它记录的是当时的测试结果，当前数据是否可用以首页快照和采集状态为准。
