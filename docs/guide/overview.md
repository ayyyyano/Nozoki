# 认识 Nozoki

Nozoki 是基于 Nuxt 4 的个人看板。看板把近期日程、设备状态、服务监控和账户数据汇集到同一页。管理员可配置内容和权限，访客只能看到站点公开的数据。

[在线演示](https://nozoki.nekro.top/)

## 首次使用

1. 按[部署指南](/deploy/)启动自己的站点。
2. 使用管理员账户登录，在[管理后台](./admin.md)启用需要的模块。
3. 在[来源接入](/integrations/)填写实例地址或凭据，完成验证后保存配置。
4. 用浏览器的隐私窗口打开首页，检查[访客可见内容](./privacy.md)。

Cloudflare Workers 版本使用 D1，Node.js 版本使用本机 SQLite。两者都保存共享设置、登录会话与采集快照。访客浏览不会直接访问各个上游来源。
