# 站点外观

进入「站点外观」可修改站点名称、主题源色、背景和卡片效果。

- **主题配色**可用现有预设，也可输入 HEX 或 RGB。
- **背景图片**可选内置图、图片地址、上传图片或无背景。上传支持 PNG、JPEG、WebP，原文件上限 10 MB。浏览器会压缩为不超过 512 KB 的静态图像。
- **背景布局**支持整页背景和顶部横幅。可设置 `cover`、`contain`、图片位置与遮罩。
- **卡片效果**控制透明度与背景模糊。

「预览当前修改」临时显示共享外观草稿。保存后应用到站点默认外观，有个人外观覆盖的访问者继续使用其本地选择。恢复内置背景需要保存配置。
